# 🚀 Quick Start

### Windows (Recommended)

1. Extract the ZIP anywhere.

2. Double-click:

```text

```

3. Browser opens automatically.

4. Begin using:

- Case-Taking Assistant
- Materia Medica Explorer
- Remedy Reference
- Repertory Search
- Manufacturer Profiles


```text

```

using Chrome or Microsoft Edge.

## Browser Issues

---

## Reports Not Exporting

Regenerate the report and try again.

---

## Slow Performance

Close unnecessary browser tabs and restart the application.
